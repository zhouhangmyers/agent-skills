# Agent Skills

面向 AI 辅助开发的可复用技能集合。把实际开发中反复出现的问题整理成明确的设计约束，用于代码实现、重构和审查。

每个技能都是独立目录，以 `SKILL.md` 为入口，可按需选择和使用。

## 已收录技能

| Skill | 用途 |
| --- | --- |
| [code-design-standards](skills/code-design-standards/SKILL.md) | 14 条代码设计规范，覆盖业务语义、代码组织、状态一致性、恢复、成本与真实交付 |

## 代码设计规范

适用于不同语言、框架和项目。根据当前任务范围检查代码，帮助智能体识别具体问题并完成相关修正。

1. 业务约束不为测试让步
2. 可选性和默认值表达明确语义
3. 校验规则有明确的权威位置
4. 同类概念使用一致的表达
5. 改动贯通实际调用链
6. 模块按职责和状态所有权组织
7. 同一业务流程按用户使用顺序组织
8. 状态一致性与持久化有明确规则
9. 异步、取消与恢复形成闭环
10. 成本与性能是设计约束
11. 完成标准对应真实能力
12. 开发环境与用户环境分清边界
13. 权限与外部输入边界明确
14. 优先复用已验证的机制

完整规则见 [SKILL.md](skills/code-design-standards/SKILL.md)。

## 使用方式

1. 下载或克隆本仓库。
2. 将需要的完整技能目录导入所用智能体支持的技能读取位置，保留其中的 `SKILL.md`。
3. 确认宿主已加载该技能。自动发现、启用和刷新方式以所用工具的说明为准。

可以这样向智能体提出任务：

> 请使用 code-design-standards 审查当前改动，列出有代码证据的问题、实际影响和建议修改位置。

或者直接用于实施：

> 请按 code-design-standards 完成本次实现，修复相关设计问题，保留约定的能力与权限边界，并说明验证结果。

## 添加技能

新技能放入 `skills/<skill-name>/SKILL.md`，在入口中说明用途、适用条件和工作规则，并更新上方技能列表。按实际需要添加辅助资源。
