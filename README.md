# Agent Skills

**持续更新的开源 Skill 仓库，把真实任务中的经验整理成 AI 可以复用的技能。**

这里会陆续分享在 AI 协作中积累、打磨的 Skill。从代码设计规范开始，后续持续扩充更多实用技能，并根据使用反馈改进已有内容。

每个 Skill 独立提供，免费开源，可以按需使用、修改，也欢迎贡献。

> **先 Star 收藏，下一份实用 Skill 也会更新在这里。**

## 如何使用

1. 下载或克隆本仓库。
2. 将需要的完整技能目录导入所用智能体支持的技能读取位置，保留 `SKILL.md` 及其依赖资源。
3. 确认技能已加载，再向智能体提出任务。具体的发现、启用和刷新方式以所用工具的说明为准。

例如，使用代码设计规范审查代码：

> 请使用 code-design-standards 审查当前改动，列出有代码证据的问题、实际影响和建议修改位置。

也可以用于实施：

> 请按 code-design-standards 完成本次实现，保留约定的能力与权限边界，并说明验证结果。

<summary>查看第一份 Skill：14 条代码设计规范</summary>

适用于不同语言、框架和项目，按当前任务范围应用。

1. 业务约束不为测试让步
2. 可选性和默认值表达明确语义
3. 校验规则有明确的权威位置
4. 同类概念使用一致的表达
5. 改动贯通实际调用链
6. 模块按职责和状态所有权组织
7. 同一业务流程按用户使用顺序组织
8. 状态一致性与持久化有明确规则
9. 异步、取消与恢复形成闭环
10. 成本与性能是设计约束
11. 完成标准对应真实能力
12. 开发环境与用户环境分清边界
13. 权限与外部输入边界明确
14. 优先复用已验证的机制

完整规则见 [SKILL.md](skills/code-design-standards/SKILL.md)。
